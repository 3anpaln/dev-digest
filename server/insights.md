# API insights

- A successful readiness probe confirms database connectivity. Workspace routes also need the user and workspace created by the seed. [Health routes](src/app.ts) · [Local auth](src/adapters/auth/local.ts)
- When a Git diff is unavailable, the review can use patches persisted during PR import. For an unexpected diff, check which source supplied it and which head SHA the PR row records. [Diff loader](src/modules/reviews/diff-loader.ts) · [PR import](src/modules/pulls/routes.ts)
- When adding structured fields to saved run logs, verify a completed trace and a failed or cancelled trace after reload. The success path uses [RunLogger.logFor](src/platform/run-logger.ts), while the [executor](src/modules/reviews/run-executor.ts) maps the event buffer separately on failure and cancellation. A field visible over SSE can disappear in either saved trace.
- 2026-11-20 follow-up to “When adding structured fields to saved run logs”. All terminal paths now use [savedLog](src/platform/run-logger.ts). For cancellation coverage, pause the first map request, cancel through the API, then release its billed response. The saved trace must include that charge and the next chunk must never start. The [lifecycle test](test/reviews.it.test.ts) caught stream closure clearing the cancellation flag before the executor reached its checkpoint.
- When a PR card appears cheaper than a multi-agent review, compare the selected run ID and its saved attempt charges with the other agents started by the same action. “Run all” creates one run per agent, and the card reports only the latest agent. [Run creation](src/modules/reviews/service.ts) · [Card cost selection](src/modules/pulls/latest-run.ts)
